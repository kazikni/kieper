## Running locally
Install The SMDE: [SMDE](https://smde.io)
Install The Deno: [Deno](https://deno.com/)
Install The Nodejs: [Nodejs](https://nodejs.org)

start client development server with `smde task run client`
and server with `smde task run server`
or cd into server and client directories and run `smde task run` for each
